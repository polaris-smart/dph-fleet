dsh-devices
DSH (DeepSeek Harness) 多设备组网插件
把你的设备变成一支舰队
$ dsh plugin add dsh-devices
✓ macOS ✓ Linux ✓ Windows 零 npm 依赖 MIT

为什么用 dsh-devices

🔍

mDNS 同网发现

同一局域网自动发现设备，零配置。

🔑

密钥配对

一个 key 完成配对，WiFi 式体验，无头设备友好。

🌐

SSH 跨网直连

公网设备直接指挥，跨网络执行命令。

📁

SFTP 文件传输

双向传文件，数据随取随用。

🩺

存活探测

一眼看清哪些设备在线、延迟多少。

🤖

Agent 原生

装完 dsh 会话内自动注册工具，对 AI 说一句话就能指挥设备。

7 个工具

fleet_discover fleet_pair fleet_ssh_exec fleet_workspace fleet_upload fleet_download fleet_status

30 秒上手

1
安装 dsh（Node 22.19+）：npx @deepseek-ai/dsh web
2
安装插件：dsh plugin add dsh-devices
3
重启 dsh，敲 /fleet 或对 AI 说 "调用 fleet_discover"

三平台实测

安装、boot、配对、远程执行、文件传输在 macOS / Ubuntu / Windows Server 2025 与 Windows 桌面版全链路实测通过。92 项测试，运行时零 npm 依赖。
